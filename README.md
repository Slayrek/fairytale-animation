# 🐾 Казка про Лицаря та Фею (Interactive 8x8 Pixel Story)

Проєкт інтерактивної візуальної новели про двох котиків.

---

## 🚀 Як запустити локально

У терміналі:
```bash
npm run dev
```
І відкрий посилання у браузері (зазвичай `http://localhost:5173`).

### Керування в грі:
* **[Лівий клік миші]** або **[Space]** / **[Enter]** — просунутися далі по сюжету (або миттєво додрукувати рядок, якщо він друкується).
* **[M]** — вимкнути / увімкнути звук.
* **[R]** — перезапустити казку з першої глави.

---

## 🎨 Гайд для художника (Спрайти 8x8)

Усі графічні ассети можна просто закидати у папку:
`public/assets/sprites/`

Гра автоматично підхопить їх замість процедурних заглушок, якщо назви файлів збігаються!

### Формат:
* **Формат:** `.png` з прозорим фоном.
* **Сітка:** 8×8 (або 16×16, якщо персонаж займає 2×2 тайли).
* **Масштабування:** зберігай спрайти 1:1 в оригінальному піксельному розмірі — рушій сам зробить кришталево чіткий цілочисельний integer-upscale без мила!

### Назви файлів:
* `knight_idle.png` — Лицар стоїть
* `knight_training.png` — Лицар тренується (дерев'яний меч)
* `knight_hero.png` — Лицар у бойовій / героїчній позі
* `knight_knee.png` — Лицар стає на одне коліно з каблучкою
* `fairy_idle.png` — Фея відпочиває
* `fairy_hover.png` — Фея ширяє у повітрі
* `fairy_happy.png` — Фея щаслива / сміється
* `fairy_sparkle.png` — Сяючі магічні крила

### Фони (Роздільна здатність 256 × 144):
* `bg_meadow.png` — Ранкова галявина та манекен (Глава 1)
* `bg_wind_cliff.png` — Вітряний гірський схил (Глава 2)
* `bg_fairy_forest.png` — Смарагдовий казковий ліс (Глава 3)
* `bg_sea_sunset.png` — Захід сонця на березі моря (Фінал)

## 🎵 Гайд для звукорежисера та композитора

Усі аудіофайли можна закидати у:
* Музика: `public/assets/audio/bgm/`
* Звукові ефекти: `public/assets/audio/sfx/`

### Формати:
* Підтримуються `.mp3`, `.ogg`, `.wav`.

### Назви треків для розділів (BGM):
1. `routine.mp3` — Затишний ранок, побут котиків, тренування (Глава 1)
2. `wind.mp3` — Драматична, героїчна мелодія про вітер і шлях лицаря (Глава 2)
3. `wings.mp3` — Казкова, мрійлива тема першого польоту феї (Глава 3)
4. `sunset.mp3` — Романтична кульмінація на березі моря + пропозиція (Фінал)

*(Поки твої власні аудіофайли не додані, рушій автоматично генерує затишний процедурний ретро 8-bit саундтрек та озвучку літер через Web Audio API)*.
